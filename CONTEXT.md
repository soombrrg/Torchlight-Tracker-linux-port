# Трекинг фарма Torchlight: Infinite

Словарь для обсуждения предметов и результатов игры. Правила расчёта дохода и границы забегов ещё не согласованы.

## Язык

**Стек**:
Количество одинаковых предметов, объединённых в одном слоте инвентаря. Размер стека описывает текущее наличие предметов, а не количество только что полученных предметов.

**Подбор**:
Получение персонажем предмета из игрового мира. Подбор — одна из причин изменения инвентаря.
_Избегать_: изменение инвентаря как синоним подбора.

**Изменение инвентаря**:
Изменение состава, количества или размещения предметов в инвентаре персонажа. Само по себе не доказывает получение нового предмета при фарме.
_Избегать_: лут как синоним любого изменения инвентаря.
